A/B Test Plan
Page and Element Being Tested
Website: Been There Iowa City

Page Being Tested: Homepage

Version A
Original homepage with no representation of anyone with a drink.

Version B
Hero image featuring a student studying in a coffee shop.

Single Element Changed
The only change between Version A and Version B is the hero image displayed at the top of the homepage. All text, layout, navigation, colors, and content will remain unchanged.

Hypothesis
I predict that Version B will generate more positive responses than Version A because it directly reflects how many visitors use coffee shops as places to study and complete schoolwork.

Reasoning
The target audience for Been There Iowa City includes University of Iowa students looking for places to study. An image showing someone studying in a coffee shop may better communicate the purpose of the website and help visitors relate to the content. A coffee drink image showcases the product, while a study-focused image highlights the experience many visitors are seeking.

AI Model
Model: ChatGPT GPT-5

Visitor Persona
You are a University of Iowa student looking for a coffee shop where you can study, complete assignments, meet friends, or spend time between classes.

Exact Prompt
Review the webpage below. Based on the information and appearance of the page, would you use this website to help find a coffee shop in Iowa City?

Answer:

Yes or No
One sentence explaining your decision.
Assignment Method
Visitors will be randomly assigned to Version A or Version B.

Odd random number = Version A

Even random number = Version B

The same AI model, persona, and prompt will be used for every trial.

Primary Outcome
Outcome Measured:

Whether the visitor would use the website to help choose a coffee shop in Iowa City.

Scoring:

Yes = 1

No = 0

Sample Size
50 trials for Version A

50 trials for Version B

100 total trials

Expected Completion Date: November 24, 2026

Comparison Method
The percentage of Yes responses will be compared between Version A and Version B.

Success Criteria
The hypothesis will be supported if Version B receives a higher percentage of Yes responses than Version A after all 100 trials have been completed.
